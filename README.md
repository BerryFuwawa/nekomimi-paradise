# Nekomimi Paradise · 猫耳乐园

一座为可爱猫娘而建的梦幻殿堂 —— 纯静态网站（HTML + CSS + 原生 JS），无需构建，直接打开 `index.html` 即可。

## 分区
- **首屏**：打字机标语、旋转光环、可点击的 SVG 猫娘、数字滚动统计
- **关于乐园**：3D 倾斜特色卡片、拍立得相册
- **猫娘图鉴**：8 位猫娘，分类筛选、翻转卡片、点赞、详细档案弹窗与台词
- **互动小屋**：摸头 / 喂食 / 逗猫棒 / 梳毛 / 热牛奶 / 戳尾巴，好感度、饱腹度、成就徽章，可拖拽毛线球
- **命定测试**：5 题性格测试，匹配你的命定猫娘
- **一日时光**：拖动时间轴，天空与日月随时间变化；乐园大事记时间线
- **梦幻画廊**：自动轮播、滑动切换、点击放大
- **心声 / 问答 / 订阅表单**

## 小彩蛋
日夜主题切换、合成喵叫声、樱花飘落、肉球鼠标轨迹……以及一个秘密入口（试试 Konami 秘籍 ↑↑↓↓←→←→BA）。

## 在线预览
在仓库 Settings → Pages 中选择 `Deploy from a branch`，分支选该分支、目录 `/ (root)`，即可通过 GitHub Pages 访问。
